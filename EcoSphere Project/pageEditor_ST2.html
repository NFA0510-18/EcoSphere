Splash Screen, Quiz and Content Page

Splash Screen

Technical Description

The Splash Screen presents the EcoSphere name, SDG 13 mission and four group members. A loader, countdown and Skip Intro link show that the Home Page will open after four seconds. JavaScript uses setInterval and an if condition to update the visible countdown, while the meta refresh performs the redirect.

Accessibility

The loader has a status role and accessible label. A visible Skip Intro link lets visitors bypass the timed screen, and the main information is provided as text rather than animation alone.

Climate Action Quiz

Technical Description

Eight climate-action cards contain an image, action name, explanation and point value. CSS Grid creates the responsive layout. JavaScript click and keyboard events select cards, while one function loops through selected items and totals their data-points. Conditions show low, medium or high feedback, and Reset clears the selections.

Accessibility

Cards can be operated with a mouse, Enter or Space. Each card updates its aria-pressed value, images include alternative text, and visible feedback explains the score without depending only on colour.

Technology and Knowledge Sharing Content Page

Technical Description

Internal links lead to sections about cooperation between nations, sharing green ideas and open-source climate research. Each section uses paragraphs and lists to explain the topic. Three local SVG illustrations support the content, while Flexbox and responsive image sizing control the layout. No JavaScript is required on this content page.

Accessibility

Descriptive headings and internal links make the long page easier to scan. The illustrations include alternative text, and the written content communicates the same ideas without requiring visitors to interpret images.

Challenges and Lessons Learned

The visible Splash countdown needed to agree with the automatic redirect, so the timer was kept simple and cleared when Skip Intro was used. The Quiz needed many cards to update one result panel; a loop and one feedback function avoided repeated scoring code. Keyboard events and ARIA states also connected interaction with accessibility.

Compliance

The pages contain appropriate educational climate material. Quiz selections remain in the browser and are not stored or transmitted. Professional language, local media, alternative text and keyboard controls support safe and inclusive use under JANET publication guidance.
