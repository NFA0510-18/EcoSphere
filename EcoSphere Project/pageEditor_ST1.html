Shared Template, Home Page, Gallery and Content Page

Home Page and Shared Template

Technical Description

The Home Page uses semantic header, nav, main, section and footer elements. A muted looping waterfall video introduces the climate theme. Three goal areas explain EcoSphere's purpose, and four linked content cards lead to the individual content pages containing multiple topics. Flexbox, spacing, overlays and reusable card styles create the layout.

Accessibility

The video is muted, images include alternative text, headings follow a logical order, and strong contrast keeps text readable over moving content. The navigation links are clear and can be reached with the keyboard.

Gallery Page

Technical Description

The Gallery contains ten image cards in a responsive layout. Each card stores the information needed for a larger modal view. JavaScript uses [querySelectorAll, getElementById] and event listeners to transfer the selected image, title and description into the modal.

Accessibility

Every image has alternative text, controls have visible labels, and the modal includes a labelled close control. Text remains available beside the images so the viewer doesn't rely on pictures alone.

Renewable Energy Content Page

Technical Description

Internal links lead to four sections about renewable methods, business and industry effects,community action and global impact. Lists separate the main points, while three to four images supported the written information by giving it a appealing look.Flexbox places images beside related text and responsive sizing keeps the page usable on smaller screens. The page uses HTML and CSS without JavaScript.

Accessibility

The page uses descriptive headings, meaningful link text and alternative text for each image. Internal links help viewers move directly to the required section, and the text remains readable when the layout narrows.

Challenges and Lessons Learned

The biggest challenge was adding javascript to the gallery. And giving the template a clean look rather than a complicated styling,made the webpage much more appealing, so overall the entire project was a challenge but a intresting one.

Compliance

The pages provide suitable educational climate information and avoid harmful or offensive material. The Gallery does not collect or request personal data. Semantic HTML, local media, alternative text and readable contrast support responsible and inclusive publication under JANET guidance.
