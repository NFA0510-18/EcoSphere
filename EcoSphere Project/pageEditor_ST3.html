Feedback Page, Team Page and Content Page

Feedback Page

Technical Description

The Feedback Page uses sections for climate programmes, community reviews and a labelled form. Required text, email, telephone, date, select and message controls collect the response. JavaScript input, reset and submit events update the character counter, check the fields, prevent an invalid submission and display a success message.

Accessibility

Every form control has a visible label, required fields are identified, and validation messages appear as readable text. Semantic headings organise the programmes and reviews, while buttons have clear action names.

Team Page

Technical Description

The Team Page uses a semantic main area and a grid of four team-member articles. Each card presents a student name, role and assigned pages. CSS Grid controls the responsive layout, while hover and focus styles reveal additional details without JavaScript.

Accessibility

Team cards can receive keyboard focus and use the same visible effect as hover. Headings identify each student, the content remains available as text, and strong colour contrast keeps names and roles readable.

Climate Communication Content Page

Technical Description

Internal links connect to four sections about clear climate science, misinformation, community awareness and working together. Each section combines headings, paragraphs, lists and a local image. Flexbox alternates image and text positions, and responsive sizing adapts the layout without JavaScript.

Accessibility

Meaningful section headings and internal links support scanning and navigation. Images include alternative text, lists break up longer ideas, and all important information is also available in written form.

Challenges and Lessons Learned

The form needed useful feedback without sending data to a server, so client-side conditions, event handling and visible messages were used. The Team cards needed the same experience for mouse and keyboard users, which was achieved with matching hover and focus styles. This work improved my understanding of form events, validation and accessible interaction.

Compliance

The pages use professional educational content. Feedback checking happens only in the browser, and the form does not transmit or store personal information. Labels, alternative text, keyboard focus and clear messages support responsible and inclusive publication under JANET guidance.
