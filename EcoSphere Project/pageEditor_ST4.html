User Profile, Sitemap and Content Page

User Profile

Technical Description

The User Profile uses a navigation header, main sections, buttons, lists and a footer. The profile begins empty. JavaScript variables store answers only during the current visit. Functions, prompt boxes and conditions control three steps, while DOM methods update the lists, message and progress bar. Skipped questions can be completed later.

Accessibility

Buttons have visible text and keyboard focus styles. Headings identify the three steps, status messages explain progress, and the profile output is organised into lists. Visitor answers are not permanently displayed or stored.

SVG Sitemap

Technical Description

The sitemap uses one inline svg. Lines show connections, rectangles form page nodes, text labels name each page, and SVG anchors make the nodes clickable. A viewBox and percentage width allow the complete hierarchy to scale without JavaScript.

Accessibility

The SVG has an image role, title and description for assistive technology. Every linked node has a descriptive SVG title, and matching hover and keyboard focus styles show which page link is active.

Business and Industry Content Page

Technical Description

Three numbered sections explain corporate sustainability partnerships, supply-chain emissions and clean-manufacturing coalitions. Lists make the main actions easy to scan. Internal links connect to section IDs, three local images use responsive sizing, and a fixed Go to Top link uses an internal anchor without JavaScript.

Accessibility

Semantic sections and descriptive headings organise the information. Images have meaningful alternative text, internal links describe their destinations, and text/background colours provide clear contrast.

Challenges and Lessons Learned

The profile needed to stay empty until a visitor answered, so empty variables and conditional DOM updates were used. The sitemap contained many links; one SVG viewBox allowed the full diagram to resize consistently. Internal section links and a fixed top link made the longer content page easier to navigate.

Compliance

The pages contain appropriate educational climate information. Profile answers remain in temporary page variables and are not sent to a server. Local images, semantic HTML, alternative text, keyboard focus and responsible language support JANET publication guidance and visitor privacy.
